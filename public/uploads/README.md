# Cartella Uploads

In questa cartella puoi inserire i file multimediali personalizzati per sostituire gli asset demo del sito del club.
I file inseriti qui saranno serviti all'indirizzo `/uploads/nome_file.estensione`.

## Come sostituire gli Asset:

1. **Logo del Club:**
   - Carica un file immagine in formato PNG con trasparenza denominato `logo.png` in questa cartella.
   - Percorso: `/public/uploads/logo.png`
   - Verrà mostrato automaticamente nell'header del club al posto dello scudo dorato di default.

2. **Video di Sfondo (Hero Background):**
   - Carica un video in formato MP4 denominato `hero_bg.mp4` in questa cartella.
   - Percorso: `/public/uploads/hero_bg.mp4`
   - Verrà riprodotto automaticamente come sfondo cinematografico della sezione iniziale del sito.

3. **Immagini aggiuntive:**
   - Puoi caricare altre immagini o foto qui (es. `banner.jpg`, `match_pic.png`) e referenziarle nei tuoi contenuti usando il percorso `/uploads/nome_file.estensione`.
